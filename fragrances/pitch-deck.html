The Goal

Build the app the fragrance community deserves — and turn it into a sustainable business.
😫

What Exists Now

  • Fragrantica/Parfumo — massive databases, but collection features are web-only, clunky
  • No real mobile app — the "apps" are wrapped websites with terrible UX
  • No layering engine — thousands of forum posts, zero algorithmic answers
  • Spreadsheets — most collectors use Google Sheets/Notes. Manual, no intelligence
  • Clone tracking — zero support for the exploding clone/alternative market
🎯

What ScentLab Will Be

  • Mobile-first collection manager — native iOS app with proper UX
  • AI Layering Engine — pick 2+ fragrances, get compatibility with reasoning
  • 500+ pre-loaded fragrances — designer, niche, clones, searchable
  • Clone tracking — see all alternatives for any designer scent
  • Creator mode — shareable collection screenshots for TikTok
  • Cloud sync — across iPhone, iPad, Android, and web
✅ Working prototype exists — 88 verified fragrances, search/filter UI, functional layering engine.
